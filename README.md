# Amazon Customer Sentiment Analysis - SyntecxHub Internship

## Overview
This project is part of the SyntecxHub Internship Program[cite: 1, 2]. It performs an end-to-end data pipeline and sentiment classification on Amazon customer product reviews to uncover customer satisfaction metrics, product rating behaviors, and key feedback insights.
